# Information Architecture & Core Flows (Stage 2)

> ux-architect artifact. Built on `ux-research.md`. Optimizes the daily loop above all.

## Navigation — five places, daily loop first
1. **Today** (home / default) — your day: what's due, what's next, one tap in. The screen you
   open every evening. Calm, short, never a firehose.
2. **Library** — the shared knowledge base: folders, tags, all resources. Where capture &
   organize happen.
3. **Team** — the shared public dashboard: all three queues, momentum, "shipped this week."
4. **Readiness** — the launch-readiness view: Build milestones + self-rated confidence, grounded
   in evidence. The "how close are we" screen.
5. **Add** (persistent action, not a tab) — capture a resource / create an item from anywhere in
   two taps.

Rationale: the daily loop (Today) is one tap from launch; capture is always one action away;
the motivational views (Team, Readiness) are present but not in your face.

## Screen inventory (v1)
- **Today** — Due/overdue (gentle), In progress, Up next; a slim "team is moving" strip.
- **Item detail** — resource embed/link, lifecycle control, sub-items (for folders), notes,
  comments, the "turn into an action" prompt on completion.
- **Library** — folder tree (editable), resource cards, tag/type/status filters, search.
- **Team dashboard** — three columns/rows of queues, collective wins first, individual lag gentle.
- **Readiness** — milestone progress + confidence, shown side by side.
- **Add / capture** — quick sheet: paste URL → type → folder → (optional) assign + deadline.

## Core flows (happy paths)
**Daily loop (the sacred path):** Open → *Today* shows ≤ a handful of items → tap one → do it →
mark complete → (Learn item) "turn into an action?" → back to a satisfying, shorter list.

**Capture → organize → assign:** Add → paste URL, pick type (Learn/Build) + folder + tags →
optionally assign to a teammate with a deadline → it lands in their queue (folder assigns as one
item with sub-items + roll-up progress).

**Apply / ship:** Item with an action → do the real work → mark **Applied/Shipped** → the app's
biggest, warmest confirmation → Readiness needle visibly moves.

**Nudge → action:** 24h-before reminder (email + in-app) or manual poke → deep-links straight to
the item → one tap to resolve. WhatsApp = one-tap wa.me share to the group.

## Principles carried from the brief
- Optimize the 100th use, not the 1st: Today stays fast and short when novelty is gone.
- Every screen has one obvious next action.
- Consumption is visible but never the headline; shipping is.
